<h1>Miso's Little Guide</h1>
<p><strong>Give your modpack a little personality!</strong></p>
<p>Miso's Little Guide is a mod that lets you create your own welcome screens, tutorials, dialogues and little character interactions for your modpack. You don't need to know how to code to get started, and you can customize pretty much the entire experience.</p>
<p>Miso is the default mascot, but you can replace her with your own character, change the themes, write your own dialogues, add buttons, sounds, animations and much more.</p>
<p>Basically, you can make your modpack feel a little more alive instead of just throwing players into a world and hoping they figure everything out ahahaha.</p>
<h2>✨ Features</h2>
<ul>
<li><strong>Custom Mascots:</strong> Use Miso or replace her with your own character and textures.</li>
<li><strong>Dialogue &amp; Tutorials:</strong> Create welcome messages, tutorials, conversations and onboarding sequences.</li>
<li><strong>Themes &amp; Customization:</strong> Change the look of the guide using themes and presets.</li>
<li><strong>Buttons &amp; Interactions:</strong> Add buttons and actions for players to interact with.</li>
<li><strong>Sounds &amp; Animations:</strong> Add sounds, different mascot expressions and animations to your guide.</li>
<li><strong>Made for Modpack Creators:</strong> Everything is set up so you can create and customize your own guide packs without having to change the mod's code.</li>
</ul>
<h2>Getting Started</h2>
<ol>
<li>
<p>Install the mod and launch your game once.</p>
</li>
<li>
<p>Find the guide-pack folder that gets created.</p>
</li>
<li>
<p>Create your own guide pack or start with the included example.</p>
</li>
<li>
<p>Add your mascot, dialogue, assets and whatever else you want.</p>
</li>
<li>
<p>Launch the game and test it!</p>
</li>
</ol>
<p>There's a README and a starter guide pack included to help you get started. You can also check the <a href="https://github.com/wtfyls/Miso-s-Little-Guide" rel="nofollow">GitHub documentation</a> if you need more details.</p>

<h2>Frequently Asked Questions</h2>
<p><strong>Can I replace Miso with my own character?</strong></p>
<ul>
<li>YES! You can use your own mascot and textures. Miso is just the default one.</li>
</ul>
<p><strong>Can I customize the guide without knowing Java?</strong></p>
<ul>
<li>Yep! You can create and edit guide packs using the files provided by the mod. Check the README and GitHub documentation to see how everything works.</li>
</ul>
<p><strong>Can I change the entire experience?</strong></p>
<ul>
<li>YES. You can customize pretty much everything, from the first bubble players see to the last dialogue and even the chat message at the end.</li>
</ul>
<p><strong>Will the guide appear every time I launch the game?</strong></p>
<ul>
<li>NUH UH. It plays once by default, so players won't have to sit through the whole thing every time they open their game.</li>
</ul>
<p><strong>Can I add my own sounds, textures and animations?</strong></p>
<ul>
<li>Of course! You can use your own PNGs, mascot expressions, animations and audio.</li>
</ul>
<p><strong>So basically, what can I customize?</strong></p>
<ul>
<li>IN SHORT YOU CAN CUSTOMIZE EVERYTHING IN THIS MOD.</li>
</ul>
